6. TECHNICAL IMPLEMENTATION
---------------------------
React/Vite retained; shared layout and independently composed route pages.
All 11 routes and a standalone 404 are prerendered during npm run build.
The output is static: publish dist only. .prerender is build-time tooling,
not a required production Node service.

Per-page initial title/description/canonical, social metadata, truthful
Organization structured data, sitemap and robots are generated. Client
navigation updates page metadata. SITE_PREVIEW=1 creates noindex output
and preserves noindex across client navigation; robots is not access control.

Local preview has exact-case routing, proper asset MIME types, GET/HEAD,
404 handling and traversal/symlink safeguards. Actual production routing,
headers, caching and redirects are NOT established by local server tests.

No analytics, tracking SDK, cookies, remote font dependency or new public
data-collection endpoint was added. Support opens the existing email or
WhatsApp channel and does not pretend to create a website ticket.
